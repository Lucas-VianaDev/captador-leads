# LeadFlow Local - Captacao e organizacao de leads

Projeto publicado: https://lucas-vianadev.github.io/captador-leads/

Sistema demonstrativo para pequenos negocios que recebem contatos pelo WhatsApp, Instagram, indicacao ou Google e precisam acompanhar oportunidades comerciais com mais controle.

## O problema

Muitos negocios pequenos perdem vendas porque os contatos ficam espalhados em conversas, blocos de notas e planilhas. Sem status, prioridade e historico, o dono esquece de retornar clientes quentes.

## A solucao

O LeadFlow Local permite:

- Cadastrar leads com origem, segmento e interesse
- Definir urgencia e valor estimado
- Calcular score de prioridade automaticamente
- Acompanhar leads por etapa do funil
- Filtrar por status e buscar contatos
- Avancar status com um clique
- Copiar mensagem pronta para WhatsApp
- Exportar leads em CSV
- Salvar dados no navegador com LocalStorage

- Profissionais que vendem pelo WhatsApp

## Como testar

1. Abra o arquivo `index.html` no navegador.
2. Clique em `Carregar exemplo`.
3. Cadastre um novo lead pelo formulario lateral.
4. Use o botao `+` para avancar o lead no funil.
5. Clique em `i` para ver os detalhes e copiar uma mensagem de WhatsApp.
6. Clique em `Exportar CSV` para baixar a lista de leads.
